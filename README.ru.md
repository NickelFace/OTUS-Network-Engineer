# Проектирование корпоративной сети — Cisco IOS / EVE-NG

> Комплексное проектирование сетевой инфраструктуры для распределённой корпоративной среды:  
> межавтономная маршрутизация BGP, OSPF с несколькими зонами, оверлеи DMVPN + IPSec и резервирование на L2 —  
> реализовано и проверено на Cisco IOS в EVE-NG.

Репозиторий документирует практические работы по сетевой инженерии — от коммутации L2  
до политики BGP. Дипломный проект моделирует реальную корпоративную сеть WAN,  
объединяющую офисы в Москве (HQ), Санкт-Петербурге, Чокурдахе и Лабытнанги.

## Продемонстрированные навыки

| Область | Технологии |
|---|---|
| Протоколы маршрутизации | OSPFv2, OSPFv3, EIGRP, BGP (iBGP/eBGP), IS-IS |
| Коммутация L2 | VLAN, STP, EtherChannel (LACP/PAgP), HSRP |
| WAN / VPN | DMVPN hub-and-spoke, GRE over IPSec, PBR с IP SLA |
| Сетевые сервисы | NAT/PAT, DHCP, NTP, MD5-аутентификация |
| Шаблоны проектирования | Трёхуровневая иерархия Cisco, разбивка на зоны, фильтрация маршрутов |
| Адресация | IPv4/IPv6 dual-stack, планирование адресов, суммаризация |

## Дипломный проект — корпоративная сеть WAN

Итоговый проект объединяет четыре территориально распределённых офиса в единый  
маршрутизируемый домен. Ключевые проектные решения и их обоснование описаны в каждой работе.

```
Москва (HQ) ──eBGP── Провайдер Триада ──eBGP── Санкт-Петербург
     │                                              │
     └──────────── DMVPN hub-and-spoke ─────────────┘
                     │            │
                 Чокурдах     Лабытнанги
```

| Работа | Тема | Что решено |
|---|---|---|
| [Адресация IPv4/IPv6](Diplom/IPv4-IPv6.ru.md) | Планирование адресов | Распределение /24–/30 по всем площадкам с IPv6 dual-stack |
| [Фильтрация OSPF](Diplom/OSPF-Filter.ru.md) | Внутридоменная маршрутизация | Разбивка Москвы на зоны; фильтрация межзонных маршрутов для ограничения flooding LSA |
| [OSPFv3](Diplom/OSPFv3.ru.md) | Маршрутизация IPv6 | OSPFv3 с теми же метриками и фильтрами, что и OSPFv2 |
| [BGP. Основы](Diplom/BGP.ru.md) | Межавтономная связность | Сессии eBGP между автономными системами; связь Москва ↔ Санкт-Петербург |
| [iBGP](Diplom/IBGP.ru.md) | Управление трафиком | Меш iBGP в Москве и у Триады; выбор предпочтительного провайдера и балансировка |
| [Фильтрация BGP](Diplom/BGP-Path.ru.md) | Маршрутная политика | Ограничение анонсов провайдера до default route; предотвращение транзитной AS |
| [PBR](Diplom/PBR.ru.md) | Политика маршрутизации | Распределение трафика по двум uplink в Чокурдахе с отслеживанием отказов через IP SLA |
| [PAT / DHCP / NTP](Diplom/PAT-DHCP-NTP.ru.md) | Сетевые сервисы | NAT/PAT для доступа в интернет; централизованные DHCP и NTP для всех офисов |
| [DMVPN](Diplom/DMVPN.ru.md) | Оверлейная WAN | GRE-туннель Москва–СПб; DMVPN phase 2 hub-and-spoke для удалённых офисов |
| [IPSec over DMVPN](Diplom/DMVPN-IPSec.ru.md) | Шифрование | AES IPSec на туннелях GRE и DMVPN |

## О себе

Работа опирается на боевой опыт работы с сетями MikroTik (MTCNA, MTCWE, MTCIPv6E)  
и переносит эти знания в синтаксис Cisco IOS и шаблоны enterprise-проектирования.

**Сертификаты:**  
✅ LPIC-2 (202-450) &nbsp; ✅ MTCNA / MTCWE / MTCIPv6E &nbsp; 🔄 Cisco CCNA 200-301 (в процессе)
